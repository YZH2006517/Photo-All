# 胶片收藏室

## 设计

用户已授权先确定设计再构建。本次保留场景已有材质和右侧座钟，名称统一为「胶片收藏室」，创作暗房独立保留。

- 卷架两层，每层 7 卷，共 14 卷。中心间距从 3.36 缩至 1.94，胶卷原比例不变。左右端保持空隙。
- 卷架选择器显示名称、占用和容量，可新建空架、切换架、将其他架的胶卷移入当前架。归属以卷 key 保存，后续导入先填有空位的架，溢出自动建架，原片和图集不变。
- 进入和返回观片时始终保留当前架。搜索仅针对当前架。架子切换时整架横移出入，不允许动画中误选；减弱动态时直接切换。
- 中央为卷架及观片工作区。右侧桌面座钟保留直立、水平向左 25°。左侧桌面加入 Poly Haven Camera 01 旁轴相机，暖白补光，原始皮革/旧金属材质，避免遮住观片视线。
- 标签「架号 / 卷数」简洁且可读；标题「胶片收藏室」，引导「选一卷，展开收藏。」。

## 实施顺序

1. 在 validation/darkroom.test.ts 验证分架、满架、去重、无效存储、移架和紧凑位置。
2. 在 product/ui/Darkroom.tsx 集中加入有界分架数据、持久化、选择器与动效，沿用原有观片和照片缓存。
3. 更新 product/ui/darkroom.css 和 Albums.tsx / App.tsx 入口文案。
4. 从官方 API 下载相机 1K glTF，校验资源摘要，整合为自包含 GLB。模型本地化并记录作者、出处和 CC0 授权。
5. 类型检查、相关单测、隔离浏览器验证切架/移架/持久化与观片回归，并截图检查比例和遮挡。

版本维持 0.10.7，本次不推送 GitHub。测试与下载中间产物放 validation/artifacts，成品资源放 product/ui/assets。
