# 0.10.6 编辑器与观片台改进

按用户已授权的交互直接实现，用户后续调整为“简单测试，不上传 GitHub，等明确指令再推送”。代码集中在现有文件，不新增应用目录。

- [x] 旋转：在共享 float32 几何流水线中以中心等比放大覆盖画布，避免透明角被白底填充；前后端源坐标映射使用相同系数。90 度旋转不额外缩放。
- [x] 放大镜：记录最近鼠标的窗口坐标，按 V 时映射到观片台；不再跳到选中图片中央。按钮开镜也使用最近鼠标位置。
- [x] 外观：全局浅色/深色切换并持久化，编辑器和导航使用同一组主题变量；关灯底色独立提供米黄、暖灰、灰黑及自定义颜色。
- [x] 导入：保留完整 SHA256 去重，使用 TIFF/RAW 内嵌 JPEG 与元数据做小尺寸分析；不能可靠取得原始尺寸时回退专业引擎。普通图片在读取尺寸后缩小分析。最多两个分析任务并行，SQLite 仍由调用线程写入，取消保留已提交照片。
- [x] 合成：嵌入编辑器工具区，当前编辑照片作为初始图层，保留合成保存、撤销、添加图层、混合与 16-bit 导出；切回调节前保存合成。
- [x] 交付：版本 0.10.6，编译与 Windows 安装包/便携包构建；仅执行针对性数值检查和本机隔离界面冒烟，不运行完整测试或安装测试。导入提速不作未经测量的倍数承诺。

根因：`pixels._geometry` 的水平校正保持画布却填充透明角，最终屏幕扁平化为白色；`analyze` 无尺寸限制地调用 `open_image`，使每张 RAW 都阻塞于完整显影；`FilmTable.showLoupe` 每次覆盖镜心为选中帧中心；编辑器独有硬编码暗色而导航使用浅色。

简单检查：9 项 Python 数值/精度/导入检查通过；1 项原尺寸缓存稳定性回归检查先失败后通过；成品前端的本机冒烟通过（主题、嵌入图层、鼠标开镜、底色保存），无浏览器异常。原尺寸缓存同时存在两个容量 Infinity 副本时，LRU 触碰会改变并列排序顺序，已加稳定 URL 次序；已解码图片的就绪确认也覆盖缓存命中。未进行完整测试或安装测试，不上传 GitHub。

## 同版本追加修改（仍为 0.10.6）

用户明确要求不递增版本、简单测试、本地重打包、不上传 GitHub。

- 实时调节：编辑器预先准备一份 1024 像素的中性屏幕底图；RAW/几何改变才重新准备。WebGL2 按帧处理曝光、对比、饱和、色温、阴影高光、黑白场、色阶/伽马、自然饱和、色调、去雾、曲线、HSL、暗角与质感；创意/胶片/开放 LUT 保留独立三维查表。交互代理只用于屏幕，空间滤波、颗粒与 RAW 临时响应为近似，停止调节后由原有高精度结果替换。硬件无法创建 WebGL2 时继续使用原有精细预览。保存/撤销与导出不接触该代理像素。
- 收纳：移除独立圆弧，把低矮磨砂弧唇接在准备区顶部；拖动时整块准备区高亮，命中范围为整个准备区与顶部 16px 接边。
- 沉浸：爱心纳入 HUD 显隐；编辑器（含合成）隐藏软件最外侧导航及遮罩，主内容从左边缘开始。
- 回收站：逐图集“彻底删除”按钮及右键入口，确认框强调只移除软件记录、保留本地原片；后端只允许销毁回收站图集，事务中写入墓碑防止旧撤销重新绑定，保留照片记录和其他图集。

本次简单检查：新增两个销毁图集检查通过（包含本地原片哈希、其他图集成员、活动图集保护、销毁后不能还原）；前端底图缓存键与原尺寸缓存稳定性两个检查通过。编译成品页面冒烟通过：阻塞保存时曝光仍改变 GPU 像素，整块准备区命中、沉浸爱心隐藏、单列编辑器、删除/取消提示均通过，浏览器异常为 0。未运行完整测试或安装测试。

## 同版本第三次更新：有序多滤镜与平面收纳区

- 去掉弧唇，按下台面照片立即进入收纳提示态；整个准备区内容模糊、发光，提示文字居中，命中范围仅为完整准备区矩形。
- 新增 filter_stack JSON 配方字段，空字符串兼容旧配方，显式 [] 代表已清空。每层包含稳定 uid、style/lut 类型、资源 id、0–1 强度及启用开关，最多 16 层，顺序从上到下。胶片独立阶段保持；叠加阶段位于胶片之后、通用色调之前。
- 右侧“滤镜”大标题替换为已添加列表，每层下方独立强度和数值输入，提供上下移、开关、移除；图库点击追加而非替换。批量追加用一个数据库事务和一个撤销步骤保留各照片的既有层。
- CPU float32 依次插值混合；GPU 用一个浮点 TEXTURE_2D_ARRAY 图集与 16 个层参数保持相同顺序，强度变化不重新请求 LUT。创意 17 阶 LUT 以对齐的 33 阶表重采样供共享处理。导出 sidecar 记录完整层与开放 LUT 署名。
- 简单检查通过：3 项后端测试（顺序、独立混合、停用、验证、批量撤销/重做、16-bit PNG 与旁注/原片哈希），3 项前端测试（旧配方、同款实例、缩略图缓存），成品页面冒烟覆盖新增/强度/上移/删除，GPU 与原生引擎像素近似一致，以及无圆弧、按住即模糊发光、整块区域收纳；浏览器异常 0。保持版本号，未做完整测试/安装测试，不上传 GitHub。
