# 创作暗房重构：器具直接驱动修图

用户纠正目标：不是完整复现冲洗教学，而是暗房操作改变照片效果；已批准以
配方架选基底、悬浮详情、拖瓶配比、拖动机械计时器为核心开始重构。
保持0.10.6、简单检查、本地打包、不自动推送与最少文件数量。

## 设计与执行计划

替换现有WetLab.tsx和其CSS作用域，不另外保留一套教学界面。四个视角为配方架、
显影台、调色台与成品台。环境用木材/深灰墙、柔和反射，瓶体为连续旋转曲面，
纸标签包裹瓶身圆柱，不再使用悬浮矩形平面。使用玻璃透射与有色液体，计时器
有实体指针/刻度，拖动指针直接改变画面，不等待倒计时。可键盘操作作为补充。

1. validation/wetlab.test.ts改为配方纯函数检查：中性不变、配比限幅、参数单调、
   保留裁切/RAW/片边/既有滤镜、角度跨界、草稿校验和本地撤销。
2. WetLab.tsx集中配方模型、Three场景与React界面。瓶子悬浮说明其效果，拖至杯上
   持续倾倒，松手归位；药液颜色/液面反映配比。选胶片基底使用现有Spektrafilm。
3. 预览复用现有LivePreview GPU管线；停手后用只读draft-preview从原片生成精确
   屏幕结果。屏幕代理不进入导出。确认后通过App共享保存/刷新路径写入配方，
   只改受控字段，保留其余参数；一次确认对应一个持久撤销步骤。
4. service.py复用现有有界预览槽和最新请求票据，增加draft-preview；model.ts增加
   同源私有连接的Blob读取函数。更新Darkroom/App入口及保存回调。
5. 重写浏览器检查：真实鼠标悬浮/拖瓶/拖指针、实时与精确预览、取消/撤销/恢复、
   一张保存、原文件不变、无WebGL降级、离开释放。原生简单检查和本地打包。

“暖金/青影/玫瑰/柔雾/银盐/辉光”、显影时间和色温均是明确的创作映射，
不宣称真实药液配方或经过校准的化学成像模型。未确认时不写入图库；草稿可恢复。

## 实际采用的开源组件

- Three.js **0.187.0，MIT**：已固定于package-lock。
- [DragControls](https://threejs.org/docs/pages/DragControls.html)：实际导入使用，
  每次通过命中确定单一瓶子组，拖拽组而非某个标签/瓶盖网格。
- [RoomEnvironment](https://threejs.org/docs/pages/RoomEnvironment.html) + PMREM：
  实际导入构建玻璃/金属所需的环境反射，不下载HDR图片。
- [RoundedBoxGeometry](https://threejs.org/docs/pages/RoundedBoxGeometry.html)：
  实际导入制作桌面/架体/托盘的倒角。
- [MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)：
  玻璃透射、折射率、厚度与清漆，限制像素比和玻璃数量。
- [Three.js MIT许可](https://github.com/mrdoob/three.js/blob/dev/LICENSE)已随运行时
  第三方声明保留。场景器具/标签为代码生成，不复制未授权模型/商标。

另调研drei/React Three Fiber与camera-controls；当前已经使用原生Three场景，
直接复用其官方插件即可，不为这次交互迁移整个渲染框架。Poly Haven确认CC0，
本轮无需下载其模型或纹理；不把调研资源列为已集成资源。

## 第四轮：红灯暗房氛围与四段流程串联

用户提供参考截图（红色安全灯、托盘、竹夹、晾片绳、手写提示），要求古典复古、
建模材质与动画精致，外形不照抄。本轮只改暗房文件：WetLab.tsx、darkroom.css。

- 氛围：四个场景共用一张清漆胡桃木长桌；暖色工作灯加红色安全灯，ACES 色调映射，
  EffectComposer + UnrealBloom（阈值 1，只让灯与高光发光）；CSS 暗角、取景框圆角与胶片颗粒。
  镜头改为真实俯角、更近的取景。
- 材质：程序化胡桃木纹与凹凸、拉丝不锈钢粗糙度贴图、纤维相纸；药瓶标签改为受光的
  旧纸印刷（双线框、斜体衬线与楷体）；釉面砖改为实例化深色亮釉。
- 器具：胶木表壳、黄铜表圈、玻璃罩与支架的计时表；带滚筋的不锈钢显影罐与滚花胶木盖；
  黄铜圈红玻璃安全灯；不锈钢、黑搪瓷、白搪瓷三只药盘与手写台卡；竹制相纸夹；弹簧木夹与下垂晾绳。
- 流程：
  1. 配方架：选中的底片盒前移转向；倒完提示下一步。
  2. 显影台：搅动改为整罐翻转（倒置搅动），完成后提示去调色台。
  3. 调色台：相纸可放入任一药盘并留在盘中；显影盘持续浸泡并让影像逐渐浮现，
     停显、定影计时完成后提示晾干；竹夹自动夹住相纸，药液有同心波纹。
     浸泡从放下到再次提起计为一个撤销步骤。
  4. 成品台：夹上晾绳后摆动、渐干；应用到照片后在绳上留下一张小样，点它换下一张。
- 桌上有一张随场景移动的手写「冲洗记录」卡，记录底片、配方、浓度、时间、色温与四步勾选。
- 界面：顶栏改为半透明渐变与步骤编号（编号 aria-hidden，不改变按钮名称）；
  左上「STEP 0n — 场景」，右上帧号，底部红色手写提示，过程中显示过程提示。

配方映射、预览与保存管线不变；药剂、时间与温度仍是创作映射。

## 第五轮设计语言：「安全灯下的一张纸」

用户反馈第四轮仍粗糙：参考成品为高位近距离俯视、不拍背景杂物、材质无明显反光、
打光柔和。要求先调研再定语言，不拘泥原有形态，然后彻底重构。

调研：
- anthropics/skills 的 frontend-design 流程：先从题材本身取材，定 4–6 个颜色与字体角色，再二次自查去掉模板感。
- bergside/awesome-design-skills 的 vintage / retro / skeumorphism 只有通用色板与字号，参考价值有限。
- WtSg 的三维暗房（GitHub PR）：安全灯形成红色光池并隐入黑暗，镜头跟着相纸在工位之间移动，
  药液只做轻微反射，另设「开灯」模式看真实颜色。

### 1 母题
主角是一张相纸。每个场景都围绕相纸要做的下一件事，其余物件只服务这一步。

### 2 镜头
- 站在台前低头看：俯角约 50°，焦距约 28°（视场角），台面铺满画面，不出现墙、架、砖。
- 画面边缘自然落入黑暗；切换工位时镜头沿台面横移，不做硬切。

### 3 光
- 头顶一盏安全灯形成一个柔和光池，从中心红橙（#ff8a5e）衰减到边缘近黑（#120302）。
- 阴影低反差、边缘柔；不做高光热点，不做泛光。
- 「看片灯」开关切换到中性白光，用来判断真实颜色。

### 4 材质
- 一律哑光、做旧：木纹低光泽，搪瓷盘与拉丝钢都是磨砂质感，相纸奶油色。
- 罐子是纸包铁罐配手写体标签。
- 药液是深色、静止的液面，只有轻微波纹，不用玻璃折射的闪光。

### 5 造型
- 少而大：每个工位 3–5 件物件，比例略圆润厚实，像手工做的道具。
- 每件物件都是一个操作入口，不放纯装饰的杂物。

### 6 两种声音（字）
- **打字机**：等宽、小号、大写，只放在黑色取景框边上。左上写场景，右上写计数（如「1 OF 4 DRY」）。
- **手写**：红色楷体，略倾斜，写在三维场景里，带一支手绘箭头指向下一件该碰的东西
  （例如「嘘，翻过来看看」）。

### 7 界面
- 整屏是一个黑色圆角取景框。
- 工具按钮从画面上撤走，改为框沿上的打字机小字链接：上一张、下一张、图集、对比、配方、撤销、应用。
- 无障碍名称保持不变。

### 8 节奏
慢、有分量；一次只动一件东西；该等的时候就让人等（「等一等…」）；尊重减弱动效设置。

| shadow | #120302 | 光池边缘 |
| bench | #5a2a1c | 台面 |
| paper | #f2e2c8 | 相纸 |
| safelight | #ff8a5e | 光池中心 |
| ink | #e8553c | 手写字 |
| lights-on | #f4efe6 | 看片灯 |

### 第五轮落地

- 场景：去掉墙、砖、木架和壁挂安全灯。药瓶与底片盒直接站在台面上，晾绳横跨画面，参考照片立在台面后方的小支架上。
- 光与材质：头顶一盏柔和的红橙安全灯，加红色天光补光；泛光强度降到 0.06。桌面、钢件、搪瓷、药液全部去掉清漆反光，玻璃改为磨砂。
- 镜头：四个工位都是高位俯视；切换时镜头沿台面横移入场。
- 看片灯：开启后改用中性白光，方便看真实颜色；只改灯光，不改配方。
- 提示：工作台按当前状态给出「底部手写一句 + 场景内短语和手绘箭头」，并实时跟随目标物件。
- 界面：整屏是黑色圆角取景框；顶部框沿是打字机字体的场景名、步骤和帧号，底部框沿是照片切换和英文小字工具链接；「应用到照片」做成红色印章样式。
- 字体令牌：打字机 Courier New / 仿宋，手写 Ink Free / 楷体，衬线 Georgia / 宋体，全部是 Windows 自带字体，不另外打包。
- 无障碍名称不变；冒烟测试 validation/artifacts 下最新的 creative-* 报告通过，浏览器无报错。
