# 独立胶片暗房：第一阶段

用户已确认轻量实时 3D、固定镜头与二维功能面板，并要求作为独立于现有板块的新板块开始构建。沿用既有代码集中、验证与成品分离、简单测试、0.10.6 与不自动推送要求。

## 范围与设计

- 新增首页与导航“胶片暗房”入口；独立全屏工作区，返回原软件。Three.js 动态加载，仅进入时创建渲染器，退出释放所有资源。
- 第一阶段完整闭环：从真实图集形成虚拟胶卷，选择胶卷、展开曲面胶片、点选帧进入照片灯箱、上一张/下一张、收卷。支持卷架镜头、桌面镜头、氛围/中性灯光和减弱动效。
- 程序化木桌、墙、架子、胶卷筒、金属、标签、台灯、接触阴影。照片使用已有 API 的编辑结果；场景光不写入图像配方，单张查看保留中性无灯光染色的照片显示。
- 胶片按实际照片比例放入固定片幅，保留完整画面；每次只加载当前窗口最多 8 帧纹理，翻页覆盖所有照片，避免大图集耗尽显存。卷架可分页、可搜索，空图集显示空卷；回收站不进入卷架。
- 不接入化学模拟、不替换现有观片台、不改原片或图库结构。首版资源自制，不拉取第三方美术素材。

## 文件与执行

1. validation/darkroom.test.ts：先检查真实图集派生、回收站排除、重复成员、分页/帧定位的边界；观察失败。
2. product/ui/Darkroom.tsx：集中数据辅助函数、独立 React 面板与场景生命周期；product/ui/darkroom.css：限定暗房作用域。
3. product/ui/App.tsx 与 Albums.tsx：增加独立入口、切换隔离与返回；依赖锁文件固定 Three.js 版本。
4. validation/darkroom_smoke.cjs：隔离本地服务，验证真实照片加载、选卷/展卷/翻页/查看/收卷、灯光、空库/无 WebGL 降级与退出重进；截图审视构图及交互。
5. 编译并检查差异，按已授权习惯生成本地 Windows 构建；不发布、不推送。

验收关注：场景真正使用 3D 几何与光照；照片不被截断或环境污染原片；选择状态一致、异常可退出；后台与退出后不保持渲染循环；大图集以分页控制纹理与网格数量。

## 实现与简单检查

- 采用 Three.js 0.187.0 与匹配类型，暗房 JS/CSS 独立动态加载。所有美术为程序化几何与 Canvas 材质；MIT 许可加入随包声明。
- 卷架胶卷移动到桌面，胶片使用裁切平面逐段显露，不拉伸照片；收回时反向过渡，避免同一卷同时出现在卷架和桌面。图片比例完整保留。
- 四项数据检查通过：真实成员、回收站/空卷、JPEG 配对优先与 RAW 保留、大图集分页边界。
- 隔离真实服务浏览器检查通过（validation/artifacts/darkroom-1793618300853）：直接点击三维物体、卷架与胶片分页、原尺寸查看、灯光、空卷、减弱动效、无 WebGL 降级、退出释放上下文；图库记录前后相同，浏览器异常 0。
- 仍为首阶段场景；没有化学模型或模拟显影，不将环境光烘焙进图片。未运行全套测试或安装升级测试。
- 只读代码审查发现固定4096长边与“原尺寸”承诺不符；5120像素样本先复现失败，再改为 size=0 完整读取，并提供按DPR换算的1:1/适合窗口切换。修复后冒烟通过（darkroom-1793618902729），真实解码宽5120与1:1尺寸均验证；复审无剩余重要问题。

## 第二次修整：暗盒结构与分段动作

用户明确要求先从卷架落桌，再从暗盒出口展开；台灯放大，接触印样从下方飘入，胶片打孔连续精细。

- 根因：原 unroll 同时驱动桶的位置和展片，纸张按 stage 直接显隐；桶缩放1.5、片高与出口均各自硬编码，孔在每帧内重排。
- 统一暗盒/片宽/片幅/出片口的几何参数，暗盒以压边金属端盖、塑料卷轴和侧面遮光绒嘴建模；卷架与桌面保持同一尺寸。
- 总进度分为移桶、落定、展片、纸张到位；反向时先收纸与胶片、最后归架。系统减弱动效时跳到最终状态，中途反向沿同一路径。
- 统一出口世界坐标作为胶片起点，胶片有留白引片，保持3:2片幅；圆角片孔按全卷等距网格绘制，不因帧边界重启。
- 台灯按桌面布局放大；纸张从画面下方滑入、轻微抬升与旋转落定，影子随三维几何变化。
- 外形参考（不复制品牌贴图）：[ILFORD 首次冲洗图解](https://www.ilfordphoto.com/wp/wp-content/uploads/2017/04/Processing-your-first-black-and-white-film.pdf)、[ILFORD 35mm 产品](https://www.ilfordphoto.com/black-white-film/35mm-film)、[Kodak 135 暗盒](https://kodak.photosys.com/collections/kodak-professional-color-pro-packs/products/portra-400-36exp-135-pro-pack-5-rolls)。比例用于视觉一致性，不作为机械加工尺寸。
- 七项数据/动作检查通过；浏览器检查 `validation/artifacts/darkroom-1793621545499/report.json` 验证先移桶再展片、出口世界坐标误差低于0.002场景单位、纸张延后入场、原尺寸查看与反向收卷。
- 只读审查发现归架中失去 WebGL 上下文可能遗留控件锁：先通过真实 context-loss 回归复现，再在出错/重建时解锁，降级收卷不再加锁。修复后上述浏览器检查通过，异常0；复审关闭此问题。
- Windows 原生简单检查 `validation/artifacts/native-1793621652870/report.json` 通过，覆盖真实照片纹理、展片完成、查看/收卷/返回、正常关闭与后台清理。只运行针对性检查，未运行全套测试或安装升级测试。

## 第三次修整：投影、顶光、部件与镜头

用户要求阴影随片展开且无重复投影、速度增加25%、移除台灯换顶光、印样可选、新增真实风格观片器和滚轮镜头。

实施路线：继续集中在 Darkroom.tsx / darkroom.css；验证仍在 validation，不增加成品目录内的测试代码。

1. 根因是照片平面仍投射未裁切的整张影子，和已裁切的胶片底层重复。改为只有底层投影，其材质的 alphaTest / clipShadows / clippingPlanes 传给真实深度材质；照片只显示像素，不投影或接收自阴影。
2. 动作时长从4.8秒降到4.8/1.25=3.84秒；适度放宽低帧率时间步上限，后台返回仍重置时间。删除全部台灯几何，主光改桌面上方。
3. 接触印样默认关闭，顶部“桌面部件”可独立开关并保存本机偏好；新观片器默认打开，带进场、顶部插片、换片和背光渐亮，空卷/图片未就绪时不亮灯。印样和观片器都开时错开桌面位置。
4. 观片器参照 [Kodak 35mm Slide and Film Viewer 官方产品](https://www.kodakphotoplus.com/products/kodak-35mm-slide-and-film-viewer) 的斜面放大窗、背光和插片槽结构；自制中性塑料壳、镜框、槽和幻灯片，不复制商标或外观贴图。属于场景交互模型，不宣称精确光学仿真。
5. 原生 wheel 监听仅挂在3D画布，滚动镜头距离65%—180%，顶部数值可复位；照片1:1查看和部件菜单滚动不受影响。退出移除监听并释放新增材质/纹理。

新增速度与缩放边界测试先失败再通过；浏览器检查增加展开中截图、唯一裁切投影配置、可选部件/换片与镜头缩放。保持0.10.6，仅本地打包、不提交或推送。

验收：9项针对性检查通过；浏览器 `validation/artifacts/darkroom-1793624108689/report.json` 通过，展开中截图确认影子只出现在已展开区且不分层，部件双开不重叠。点击胶片/缩略图装入观片器，点击观片窗或“查看照片”进入原尺寸查看；无WebGL时直接查看原图。未运行全套测试。

Windows 原生简单检查 `validation/artifacts/native-1793624265433/report.json` 通过：真实照片、统一投影、默认观片器、滚轮缩放与复位、查看原图、收回/返回和关闭清理；浏览器异常0。最终只读复审无剩余重要问题。

## 第四次修整：真实输片与两类观片器

用户要求照片和胶片一起伸缩；新增胶片穿入式观片器，原部件改名电子观片器，插片前全黑；导航栏自动下沉，部件全关时可以拖片。

- 根因是展片只移动右侧裁切边界，全部图片世界坐标不变。改为固定出口世界裁切面，整组底片/照片统一平移；曲面以平移后的世界坐标计算，保持出片口平顺衔接。回收沿相同路径反向。
- 胶片观片器直接围绕主胶片建模，无第二张照片表面；窗口、漫射背光、前后滚轮、手柄和底座均由代码生成。选择帧时按实际片距输送主胶片，侧轮/手柄同步运动。
- 原部件改名电子观片器，独立开关；插片未完全到位或当前图片未加载时屏幕颜色精确为0，到位后再渐亮。默认胶片观片器开，其余关，已有本机偏好保留。
- 导航栏用CSS整体下沉，只剩10px窄边；固定底部感应区与展开内容共同维持悬停，避免面板上移后鼠标失去命中。在系统减弱动效时同样可用；键盘焦点仍可展开。
- 所有部件全关、展片完毕后，鼠标在胶片上显示抓手，采用pointer capture与场景平面交点拖动，范围限制在当前页片长内；释放只同步选择、不误开原图。pointercancel/lostpointercapture、换页/离开/启用部件时释放拖动。

执行和验证仍集中在原Darkroom.tsx/CSS与validation，版本0.10.6，不推送。11项数据/动作检查通过（新增输片/插片黑屏测试先失败再通过）；浏览器 `validation/artifacts/darkroom-1793626360354/report.json` 通过，含真实帧锚点与底片位移一致、光学窗口对帧、黑屏门控、底栏悬停、实际鼠标拖片、末页/上下文恢复/无WebGL降级，浏览器异常0。截图核对胶片一体移动与窗口穿片；只读审查无剩余重要问题。

Windows 原生检查 `validation/artifacts/native-1793626521524/report.json` 通过：默认胶片观片器、底边唤出导航、原图查看、镜头缩放、收卷返回及窗口关闭/后台清理。仅针对性简单检查，未运行全套测试或安装升级测试。
