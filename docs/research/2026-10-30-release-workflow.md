# 0.9 图集与分发实施计划

目标：紧凑的图集整理、明确选片导出、简化的高精度编辑器，以及可离开开发工作区运行的 Windows 安装 EXE。

## 确定设计

- 图集移入回收站，保留 30 天；可恢复，到期只清除图集与成员记录，磁盘原片保持只读。回收站与活跃图集分开，已删图集不能继续导入。
- 左导航为可展开抽屉，默认收起为窄栏。分类默认一行常用条件；更多筛选展开，全部数字按其他条件实时计算。增加饱和度、对比度、方向、文件类型、像素、启发式质量、风格和胶片型号。
- 图集取消合成项目入口；编辑器保留图层入口。裁剪/旋转合并为构图，移除细节/修复/局部入口，历史配方继续可渲染。参数滚动区与底部按钮分开。
- 导出严格基于当前勾选照片，编辑器只导出当前一张；不再隐式优先全部爱心照片。无选片不启动导出，窗口明确数量。支持同一文件夹或按图集子目录；每张选片只写一份。提供终止，保留已完成文件、清理当前未完成输出。
- 独立 CPython 运行时、图像依赖、RawTherapee、CLIP 与胶片 LUT 随包提供，用户数据放 AppData；NSIS 安装器检测 WebView2。源码、第三方许可证、对应源码材料与安装包分开发布。

## 0.9.1 补充与验证

补入可取消导入：目录逐项枚举、源文件分块读取、RAW 子进程和 regroup 均响应取消。已提交的照片与图集成员保留，取消后可续导且不会重复。真实 NEF 显影取消在约 0.3 秒内返回。`import_cancel_smoke.cjs` 实际走文件夹导入、UI 终止和续导，验证第一次保留 1 张、续导新增 2 张、全部原片 hash 不变。

侧栏使用 120ms hover intent 和 350ms 离开延迟，内部移动/键盘焦点保持展开，导航点击和 Esc 关闭后不会马上反开；减少动效偏好也已验证。封面曾在 1080px 下出现 467×1533px 的竖图撑高问题，现以固定比例外框与绝对定位内部 grid 隔离图片本征尺寸；6 种横竖混合封面在 1080/1440 均与新建卡同高。

新增共享 RAW/JPEG 显示偏好。同目录、同 stem、包含 RAW 与 JPEG 两种格式时才隐藏非优先版本；独立照片与不同目录同名不受影响。观片范围保留配对成员以支持随时切换，所有布局和计数使用派生可见列表，不删原文件。真实 NEF+JPEG 的首页、图集与观片切换已验证。

单元测试为 55 项前端与 108 项 Python；0.9 安装/便携包的迁移、安装、启动、关闭、卸载与库保留已完整通过。0.9.1 使用相同分发结构重打包。第三方对应源码 zip 记录 61 个匹配源包，99 个 DLL/辅助程序与 548 个图标均逐文件核验。原始照片、模型、数据库、验证生成图和构建依赖不进入源码 Git。
