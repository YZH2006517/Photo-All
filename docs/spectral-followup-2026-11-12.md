## 实际修改

1. GPU 使用显存输入/输出和批量传输；回读缓冲优先 HOST_CACHED 内存，避免 CPU 从写合并内存逐行低速读取。按显存容量限制批次，最多2097152像素，四个 I/O 缓冲合计不超过96MiB。
2. 耦合剂高斯/指数扩散按颜色平面复用输入，减少四轮重复 RGB 拆分、组装和无效乘方。沿用上游卷积核、边缘与混合权重，独立数值回归误差≤3e-12。
3. Windows 主进程与光谱进程用一份命名共享内存交换 float32 原尺寸像素，避免每次写读两份数百MB临时 NPY。内存提交不足时保留文件回退。两个版本的 Python 已通过实际跨进程测试。
4. 完整光谱结果缓存分原尺寸/小图两池，默认384MiB+24MiB；实际输入像素、全部物理参数和质量模式参与键。返回独立可写副本；后续阴影、LUT、片边和加速导出复用；改变胶片前曝光仍重新显影，精算不复用加速结果。
5. 普通 LUT 使用同一自研 Vulkan 库，服务进程内串行保护上下文；硬件或驱动不可用回退原 NumPy 路径。中性解码缓存现在也可给同精度导出使用。
6. 16-bit PNG 改为原生 libpng 编码，仍逐样本保留16位值及同样的 sRGB 意图标签；RGB/RGBA、透明度、16-bit PNG/TIFF 往返均经过验证。
