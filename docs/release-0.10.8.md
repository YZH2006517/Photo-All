# Photo All Studio 0.10.8

本版集中改进编辑响应、光谱胶片计算、共享缓存与胶片收藏室的亚克力展廊。

## 更新项

- 自研 C++/Vulkan 后端加速颜色变换、光谱积分、LUT 与颗粒采样。颗粒按乳剂子层计算，避免九通道整帧中间数组。部分片种高光曲线回折时继续使用 GPU 采样。
- 颗粒、光晕、耦合剂采用可复用缓冲区和 GPU 空间滤波。显存或 FP64 能力不足时使用 CPU 滤波。
- 编辑时先显示交互预览，再更新原尺寸。默认加速计算，导出可选逐像素精算。
- 缓存已解码原图、完整光谱结果、已显影底片和颜色计算准备结果。调节后续阴影、叠加 LUT、切换片边及导出复用适用结果。改变胶片前曝光会重新显影。
- 取消过期预览时保留计算进程、GPU 资源和缓存，减少连续调参时反复初始化。两个 Python 进程通过共享内存传递图像。
- 颜色准备缓存可跨进程和重启复用，校准和颜色表准备减少首次 JIT 编译。缓存损坏会重建，并限制占用。
- 原生 16-bit PNG 编码与完整精度解码缓存，保留 PNG/TIFF 的高位深导出。
- 光谱运行库采用无界面依赖配置并精简标准库和未使用资源，保留片种、成像代码与许可证。
- 亚克力展廊改为双层透明夹片、抛光倒角与柔光箱环境反射。优化材质、机位和场景进退动画。
- 收藏室和展廊的氛围灯／中性灯采用约 0.8 秒渐变。切回收藏室恢复之前的卷架或桌面视角。

## 实测数据

测试显卡为 NVIDIA RTX 5080 16 GB。RAW 样本为 DSC_0772.NEF，6056×4032。JPEG 样本为 DSC_1073.JPG，4000×6000。以下记录来自本版开发期间的实际测试。复杂配方包含 Portra 400、颗粒、光晕、耦合剂、预闪和自定义色温。

| 操作及条件 | 实测 |
| --- | ---: |
| RAW 浏览器复杂组合原尺寸更新，上轮到本轮相同流程 | 35.21 → 17.37 秒 |
| RAW 浏览器首次可见胶片预览，已有科学运行库缓存 | 3.93 秒 |
| 原尺寸计算中再次调参的可见响应 | 0.40 秒 |
| RAW 复杂配方完整原尺寸接口，引擎已就绪 | 14.17 秒 |
| JPEG 复杂配方完整原尺寸接口 | 14.32 秒 |
| JPEG 胶片后调阴影 / 叠加 LUT | 1.62 / 2.00 秒 |
| JPEG 复用胶片结果导出 JPEG / TIFF16 / PNG16 | 1.81 / 1.85 / 5.76 秒 |
| JPEG 改冲印参数，复用底片 | 2.41 秒 |
| JPEG 改胶片前曝光，需要重算 | 14.82 秒 |
| 真实任务取消，保留相同计算进程 | 0.16 秒 |
| 常规无颗粒光谱核心计算，上轮到本轮 | 11.69 → 4.71 秒 |

独立冷启动记录采用 606×404 的真实 RAW 预览输入。全新空缓存首次复杂配方约 11.84 秒，保留磁盘缓存后结束进程并重启约 2.87 秒。首次安装仍需初始化。浏览器首显和完整原尺寸计算采用不同口径，交互预览不作为最终导出像素。

常规无颗粒配方相对 CPU 精算的抽样色差 ΔE00 P95 为 0.00362，最大 0.02103。GPU 颗粒采用同一概率模型的独立随机场，按均值、方差和空间滤波验证。加速颜色计算使用 LUT 近似，逐像素精算使用 CPU 路径。不同设备、片种和参数组合会影响时长。

光谱运行库组件从 389,090,761 字节减少到 356,922,521 字节，减少约 30.7 MiB。这是组件文件量，发行包的实际体积以下载页为准。

## 验证范围

性能与计算改动已有 56 项后端、精度和接口回归，以及 19 项真实 RAW 浏览器流程检查通过。浏览器实际收到 6056×4032 更新。后续亚克力材质、切场和灯光修改按用户要求仅执行编译，实际观感与安装升级尚未运行验证。

Windows 10/11 x64 预发布版本，当前构建未签名。完整解压便携包后打开 Photo All Studio.exe，保留同目录 runtime。安装包支持手动覆盖升级。
