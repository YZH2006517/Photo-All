# Photo All Studio 0.10.6

相较 [0.10.5](https://github.com/YZH2006517/Photo-All/releases/tag/v0.10.5) 的更新。

![0.10.6 更新内容](https://github.com/YZH2006517/Photo-All/releases/download/v0.10.6/update-0.10.6.png)

## 本次更新

- **实时调节**：光线、色彩、曲线等滑杆提供 WebGL2 即时屏幕预览，停止调节后替换为原引擎精细结果；不支持 WebGL2 时沿用精细预览。旋转/拉直自动覆盖画布，修复白边；图层合成融入编辑器。
- **滤镜重构**：顶部已添加缩略图、“滤镜 / 收藏”页签、分组卡片；点击预设替换当前层，点击“＋”再叠加。最多 16 层，各自调整强度、顺序与开关；强度紧跟所选预设行，支持输入数值。保留旧配方并接入批量撤销、精细渲染和导出旁注。
- **观片台**：V 键按鼠标位置开镜；关灯底色可选米黄、暖灰、灰黑或自定义。移除收纳圆弧，按住台面照片时整块准备区模糊发光并显示提示，可拖到准备区任意位置收纳；沉浸时同步隐藏爱心。
- **界面统一**：侧栏图标位置固定、展开过渡重做，图集与全部照片使用不同图标；图集顶部删除宣传文案、压缩布局。更换软件图标与随主题变化的 Windows 标题栏。编辑器隐藏最外层导航，并在顶部加入深浅色切换。
- **图集管理**：名称留空自动创建“未命名图集”及编号；回收站增加彻底删除确认，只移除软件记录，保留电脑本地原片，防止旧撤销恢复已销毁图集。
- **导入与缓存**：支持的 RAW 优先用内嵌预览分析，最多两个分析任务并行；缺少可靠预览时回退专业引擎，仍保留完整 SHA256 去重。修复原尺寸缓存候选切换和缓存命中就绪状态。新包用独立临时目录组装，避免清理运行中的便携目录。

126 款开放 LUT、胶卷播放、16-bit PNG/TIFF 导出等既有能力继续保留。实时预览是屏幕代理；RAW 临时响应、颗粒和空间滤波可能近似，完整导出重新读取原片并使用原有高精度引擎。

## 下载

Windows 10/11 x64：

- `Photo-All-Studio_0.10.6_x64-setup.exe`：安装或覆盖升级。
- `Photo-All-Studio_0.10.6_windows-x64.zip`：完整解压后打开 `Photo All Studio.exe`，保留同目录 `runtime`。

图库与配方在用户 AppData，原片保持只读。内置 Python、RAW、离线识图和 LUT，无需开发环境。需要 WebView2，首次引导安装需要联网。通过 GitHub 下载手动升级。
